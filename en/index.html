iPhone: TestFlight beta

The iPhone app is currently available as a closed TestFlight beta. To request access, email dabuldakov@mail.ru with the subject “muzea TestFlight” and include the email of your Apple ID.   1. Install TestFlight from the App Store.
  2. Email dabuldakov@mail.ru with your Apple ID email.

  4. Open TestFlight and install the muzea build.

Requires iPhone with iOS 16 or newer. This is a beta build: bugs are possible and features may change. The regular Android APK is available below.

Phone data access — no extra permissions

muzea does not request access to your entire photo library or address book. Photos, videos and files are selected through the built-in Android and iOS system pickers: the app only receives what you explicitly choose.

  • Photos and videos — the system media picker (Android Photo Picker, iOS Photos Picker). The rest of your gallery is not available to the app.
  • Files — the system file manager; access only to the document you pick, without reading all of storage.
  • Contacts — your phone's address book is never requested or read. The contact list in muzea consists of app users you add by username inside muzea itself.
  • Camera and microphone — only while recording a video note or a voice message. Without permission, recording simply does not start.
  • Notifications — optional: you can skip or disable them in settings; the rest of the app keeps working.
  • Saving to the gallery — a separate permission, requested only when you tap “Save”.

Any permission can be revoked in Android or iOS settings. See the Personal Data Processing Policy for details.

How to install

  1. Download the APK with the button above.
  2. Open the file from "Downloads" — Android will ask whether apps from this source may be installed.
  3. Allow installation from "Files" or from the browser and return to the installer.
  4. The app will appear in the list as muzea.

Requires Android 7.0 or newer. The app is free and contains no ads.
